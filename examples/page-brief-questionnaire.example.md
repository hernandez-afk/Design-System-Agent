# Page brief: Build a questionnaire

## Purpose

Organizers build the feedback questionnaire attendees fill in after a hackathon.

## Users and context

- **Who:** hackathon organizers, a few times a year
- **Device:** mostly laptop, sometimes phone
- **Brand guidelines:**

## Where it fits

- **Arrives from:** the hackathon's admin page
- **Goes next:** back to the hackathon's admin page
- **Pages that should link here:** the hackathon's admin page

## Goals (ranked)

1. Organizers can put a questionnaire together quickly.
2. It should feel simple, like Google Forms. Easy to reorder questions.

## Must have

- Questions of a few types
- Reordering

## States

- No questions yet

## Out of scope

- Analysing the answers
